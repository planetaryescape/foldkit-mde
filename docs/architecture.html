What happens when you type?

Browser input → adapter reads changed DOM → source + selection message → core updates history → Foldkit synchronizes the document → JSON is projected again.

Unchanged blocks and adjacent original separators retain their source. Structural edits intentionally change the affected structure.

Who owns the hard parts?

  • Effect: schemas, scoped listener lifetimes and runtime work.
  • Foldkit: messages, rendering and the application loop.
  • Host: plugin choice, saving, publishing and future Alchemy infrastructure.
  • Fence: strict types, lint, generated history tests, browser checks and commit hooks.

Current JSON is export-only. JSON editing/import must validate a declared format and produce a transaction, never write a separate state store. Full CommonMark, dynamic plugin registration and multi-editor embedding remain future work.
